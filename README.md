## The Excel Model — `RIL_DCF_Model.xlsx`

Five sheets built with `openpyxl`, following IB colour-coding conventions (blue = inputs, black = formulas, green = cross-sheet links).

### Sheet 1 — Historical Financials
Ten years of P&L, Balance Sheet, and Cash Flow data (FY17–FY26) sourced from Screener.in. Derived metrics:

- EBITDA = PBT + Depreciation + Interest − Other Income
- EBITDA Margin, EBIT Margin, PAT Margin
- Net Fixed Assets = Net Block + CWIP
- Net Debt = Borrowings − Cash
- Free Cash Flow = CFO + CFI

### Sheet 2 — Assumptions
All model inputs in one place:

| Input | Value |
|---|---|
| Risk-free rate (Rf) | 7.10% (10Y G-Sec) |
| Beta (β) | 1.05 |
| Equity Risk Premium (ERP) | 5.00% |
| Cost of equity (Ke) | 12.3% |
| Pre-tax cost of debt (Kd) | 8.50% |
| Tax rate | 25.0% |
| WACC | **11.0%** |
| Terminal growth rate | 5.0% |

### Sheet 3 — DCF Valuation

FCFF-based DCF over a 5-year projection horizon (FY27–FY31):

```
FCFF = EBITDA × (1 − Tax) + D&A × Tax − ΔWorkingCapital − CapEx
EV   = PV(FCFFs) + PV(Terminal Value)
Equity Value = EV − Net Debt
Implied Price = Equity Value / Shares Outstanding
```

| Output | Value |
|---|---|
| Enterprise Value | ₹7,71,995 Cr |
| Net Debt | ₹2,56,985 Cr |
| Equity Value | ₹5,15,010 Cr |
| **Implied Price** | **₹381 / share** |
| Market Price | ₹1,309.5 |
| Premium / (Discount) | −71% |

**Why the gap?** Single-entity FCFF DCF cannot capture the embedded optionality in Jio Platforms (estimated ₹7–9 lakh Cr standalone), Reliance Retail, and the ₹75,000 Cr New Energy platform. The market is paying ~₹929/share for those options above the hard earnings stream. A proper SOTP would close this gap.

### Sheet 4 — Comparable Company Analysis

FY25 peer set (conglomerate / large-cap India):

| Company | EV/EBITDA | P/E | ROE |
|---|---|---|---|
| Reliance Industries (FY26) | 11.3x | 21.9x | 9.3% |
| Adani Enterprises | 24.4x | 71.6x | 9.8% |
| Tata Motors | 5.4x | 11.2x | 23.6% |
| Larsen & Toubro | 17.8x | 32.6x | 15.9% |
| Bharti Airtel | 15.4x | 36.3x | 23.2% |
| ITC | 12.4x | 17.0x | 29.3% |
| **Peer Median** | **15.4x** | **32.6x** | — |

RIL trades at a ~26% EV/EBITDA discount and ~33% P/E discount to peer medians, reflecting heavier capital intensity and near-term FCFF compression.

### Sheet 5 — Sensitivity Analysis

2D WACC × terminal growth grid (WACC: 9%–13%, g: 3%–7%). Base case (11%, 5%) highlighted.

## Running the Scripts

### Requirements

```bash
pip install openpyxl
npm install docx          # or: npm install -g docx
```

LibreOffice is required for formula recalculation (used by `recalc.py` from the xlsx skill).

### Generate the Excel model

```bash
python build_model.py         # Creates RIL_DCF_Model.xlsx
python update_comps.py        # Fills peer data into the Comps sheet
```

### Generate the Word note

```bash
node build_note.js            # Creates RIL_Investment_Note.docx
```

## Key Takeaways

1. **FCFF DCF is a floor, not a ceiling for conglomerates.** For diversified companies like Reliance, single-entity DCF systematically undervalues embedded optionality in high-growth subsidiaries. SOTP is the appropriate framework.

2. **RIL trades at a discount on trading multiples.** 11.3x EV/EBITDA and 21.9x P/E vs peer medians of 15.4x and 32.6x respectively — the gap is partially justified by higher capex intensity and lower near-term FCF conversion.

3. **The New Energy bet is the key swing factor.** ₹75,000 Cr of committed capex across solar giga-factories, green hydrogen, and energy storage is not priced in our model. Its payoff horizon (FY28+) and margin profile are the primary bull-case variables.
